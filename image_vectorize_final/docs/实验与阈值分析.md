# 实验与阈值分析

本文记录方案定型过程中的实验数据：阈值如何标定、每个特征组件为什么
留或删、通用性如何验证。所有数字均为实测，测量方法见文末。

## 1. 阈值标定

在 test_samples 两组用例上统计两类关键距离：

| 量 | 定义 | 实测值 |
| --- | --- | --- |
| T_low | 同页对（model/real 同名）距离的最大值 | **1.258** |
| T_high | 新页对（缓存中不存在的 real 图）与所有缓存图距离的最小值 | **1.500** |

判定阈值必须落在 (1.258, 1.500) 区间内才能两组全对。取中点
**1.38**，两侧各留约 0.12 的安全边距——比"贴着边界取值"更能容忍
训练集之外的新样本。

两个卡边界的关键样本（它们决定了区间上下限）：

- **T_low 由过曝的 real a06 决定**：整页反光把高光信息截断到不可逆，
  是最难的同页对，也是"高光压缩 + LCN"这一组合存在的原因；
- **T_high 由 real b01 ↔ model b11 决定**：b01 与 a01 画面内容相似但
  纵横比不同。缩放到正方形网格的非等比拉伸恰好把纵横比差异保留在
  低频布局里——这个"副作用"是区分相似不同页的有效机制，调参全程
  注意保护，未被后续改动破坏。

## 2. 特征设计的消融实验

demo 基线（aHash 16×16 + L2）在波西和皮普组只有 50% 正确率，以下按
实际探索顺序记录每一步的取舍。

### 2.1 结构通道：从失败到可行的路径

| 尝试 | 结果 | 教训 |
| --- | --- | --- |
| 纯灰度 DCT（32×32） | 波西和皮普 50%，过曝样本 a06 与粉色沙发页 a05 对角错配 | 布局特征扛不住过曝截断 |
| + HSV 色相通道 | **更差** | 白底低饱和区色相接近随机，z-norm 把噪声放大 |
| + 直方图均衡 | 全面变差 | 均衡同时放大了翻拍图的压缩伪影 |
| + 色度归一化 `rgb/(r+g+b)` | argmin 错配清零，但同页对最大距离 1.763 仍高于异页最小值 1.179 | 颜色方向正确，还需解决过曝 |
| + 高光压缩 clip | 截断点 180→120/255 期间 T_low 卡在 1.617 不再下降 | 单靠全局变换无法补偿局部光照不均 |
| clip + 局部照度归一化 | **间隔首次转正（+0.023）** | 过曝补偿的正确组合：全局压高光 + 局部除均值 |
| 网格提到 64×64、DCT 取 24×24 | 间隔升至 +0.072 | 更细的结构细节带来区分度 |
| 颜色权重扫描 | wcolor=0.6 时间隔最大（+0.235） | 颜色过重会干扰布局判断 |

最终配置：`grid64 / keep24 / clip120/255 / LCN r=3 eps=0.03 / wcolor0.6`，
T_low=1.258、T_high=1.500。此配置下最差同页对已从过曝的 a06 转移到
常规样本 a11，说明过曝问题在该配置下基本解决。

### 2.2 尝试过但未采用的组件

为确认方案没有明显遗漏，对以下组件逐一做了独立消融，均无正收益：

| 组件 | 结果 | 原因分析 |
| --- | --- | --- |
| 分块 DCT（2×2 / 3×3） | 间隔降至 +0.198 / +0.161 | 整页全局构图比局部块信息更有区分力 |
| Tukey 空间窗 | 负收益 | 边缘信息对布局判别有贡献，不宜压制 |
| DCT 频率加权（α=0.3/0.6/1.0） | 全部负收益 | 低频内部各系数的重要性并不单调 |
| knee 软压缩（替代硬 clip） | 负收益 | 软压缩保留了过多高光段差异 |
| 色度减 1/3 中心化 | +0.230，逊于 z-norm 的 +0.242 | z-norm 对色度平面更合适 |
| 色度稳健标准化（median/MAD） | 负收益 | 16×16 采样下 median 估计抖动大 |
| 高斯核 LCN | 略逊 box 均值 | box 已足够，高斯权重无额外收益 |
| 色度 gamma、cgrid=20 | 均无改善 | — |

另做 clip × eps × wcolor 三参数联合网格扫描（27 组）：最优点附近平坦
（间隔 +0.20~0.25），与现有参数的组合差异仅 0.004（噪声级）。**保持
参数不变**，避免向噪声过拟合。

## 3. 合成退化压力测试

**动机**：官方样例只有 26 张 real 图，退化类型与强度有限，需要比真实
分布更狠的验证来确认通用性。

**方法**：对全部 28 张 model 图，各生成 11 类退化版本作为"假 real"
（退化强度刻意超出真实上传图的范围），要求退化图仍检索回原图
（argmin 正确）且距离低于阈值 1.379：

| 退化类型 | 通过 | 率 | 退化类型 | 通过 | 率 |
| --- | --- | --- | --- | --- | --- |
| 亮度 +30% | 28/28 | 100% | JPEG 重压缩 q30 | 28/28 | 100% |
| 亮度 −30% | 28/28 | 100% | 旋转 2° | 28/28 | 100% |
| 对比度 −40% | 28/28 | 100% | 旋转 4° | 27/28 | 96.4% |
| gamma 0.6 | 28/28 | 100% | 高斯噪声 σ=10 | 28/28 | 100% |
| gamma 1.6 | 28/28 | 100% | 椭圆反光斑（中心 +90） | 28/28 | 100% |
| 内容裁切 12% | 0/28 | 0% | **总计** | **279/308** | 90.6% |

解读：

- **9/11 类退化 100% 稳定**。亮度、对比度、gamma、重压缩、小角度
  旋转、噪声、反光斑——clip + LCN + 色度的设计目标全部兑现；
- **旋转 4° 的 1 例为压线失败**（argmin 仍正确，仅距离略超阈值）；
- **内容裁切 12% 全灭**是预期内的边界：裁掉的是页面内容本身而非
  白边，信息在输入侧已经丢失，任何缓存侧特征都无法恢复。实测过
  "内容 bbox 对齐"方案（检测非白区域并裁齐）——它修复不了内容丢失，
  反而使整体间隔从 +0.242 恶化到 +0.046（b01↔a01 这对相似页会被
  对齐到一起），确认放弃。本任务的输入设定为"书页**展平后**的图片"，
  展平意味着上游已完成页面定位与取景，裁切 12% 属超纲输入，记录为
  已知边界而非缺陷。

完整输出见 [`results/压力测试与边界验证.txt`](../results/压力测试与边界验证.txt)。

## 4. 边界输入与异常行为

| 用例 | 结果 |
| --- | --- |
| PNG 大图 / 16px / 64px / 灰度 / RGBA / CMYK JPEG / 单色图 / 3000px 超大图 | 全部输出 (1344,) float64 有限向量 |
| 空字节 / None / int | 均在入口抛带信息 `ValueError` |

## 5. 局限与改进方向

1. **不支持大角度旋转与内容裁切**（§3），依赖上游保证展平与取景完整；
2. 特征为手工设计，若未来样例分布大幅变化（如彩页占比极高的绘本），
   可考虑用小型 CNN 蒸馏特征替换结构通道，但需重新校验 100ms 约束；
3. 阈值 1.38 基于当前 26 张 real 图标定。样例扩充后建议重跑 §1 的
   区间统计，确认两侧边距仍在 0.1 以上。

## 测量方法

- **距离区间**：逐 real 图计算与所有 model 图的欧氏距离；同名对取
  最大值即 T_low，新页对取最小值即 T_high；
- **压力测试**：对每张 model 图施加退化 → 以 1.379 为阈值检索全部
  model 向量，要求 argmin 命中原图且自距离低于阈值；
- **正确率与耗时**：仓库根目录 `main.py`（官方评测脚本）。
