# 算法详解

本文逐个环节说明 `image_vectorize.py` 在做什么、为什么这样设计。
整体结构一句话概括：**用两段互补的手工特征描述一张书页——灰度低频
布局管"哪里亮哪里暗"，色度布局管"哪里偏什么颜色"——拼接后用欧氏
距离比较**。全程 numpy/Pillow 实现，单张毫秒级，不依赖任何学习模型。

## 0. 任务设定与输入假设

- 输入：书页**展平后**的图片字节（JPG / PNG，长边不超过 1600 像素）。
  "展平"意味着上游已完成页面定位与透视校正，本函数不做页面检测。
- 输出：一维 float64 向量（1344 维），各段 L2 归一化。
- 匹配规则：同一页面的 model（服务端缓存图）与 real（客户端上传图）
  向量距离 < `DIFFERENCE_THRESHOLD`(1.38)；不同页面（包括缓存里不存在
  的新页）距离 > 1.38。
- 约束：单核单张 ≤ 100 ms；允许 numpy / Pillow 等第三方库，不调用大模型。

上传图相对缓存图的真实退化包括：重新压缩、轻微透视/弯曲形变、边缘
裁切差异、整页或局部过曝反光、亮度对比度偏移。算法的全部设计决策
都围绕"这些退化下距离要稳，不同页之间距离要开"展开。

## 1. 解码：JPEG draft 快速路径

```python
img = Image.open(io.BytesIO(image_bytes))
img.draft("RGB", (128, 128))   # min_edge = 网格边长 × 2
img = img.convert("RGB")
```

`draft()` 是 JPEG 解码器的 DCT 域降采样开关：解码器直接按 1/2、1/4、
1/8 档输出缩小图，省掉"全尺寸解码再缩小"的浪费。一张 1600×1100 的
页面按 1/8 档解码只需数毫秒。该调用对非 JPEG 格式是无害的空操作。

短边下限取 128：结构网格是 64×64，draft 结果只要不小于它就够，留 2 倍
冗余保证缩放质量，同时避免解码不必要的像素。

## 2. 结构通道（576 维）：灰度低频布局

### 2.1 缩放到 64×64 灰度网格

双线性插值。4096 个采样点足以刻画整页构图，后续所有运算规模也因此
被压到毫秒级。

### 2.2 高光压缩：对过曝的补偿策略

```python
arr = np.clip(arr, 0.0, 120/255) / (120/255)
```

书页翻拍中最具破坏性的退化是**反光过曝**：大片像素被截断到 255，信息
不可逆丢失——实测重度过曝样本与标准图的结构特征距离可以逼近 1.0
（对 L2 归一化向量而言即近乎正交）。既然无法恢复，就把高光段的数值
范围**压缩**掉：[0, 120/255] 线性拉伸到 [0, 1]，让过曝区与标准图的浅色
区落到相近数值区间。截断点的消融显示从 180/255 收紧到 120/255 期间
同页/异页间隔单调改善，再收紧不再变化，120/255 即停止点。

### 2.3 局部照度归一化（LCN）：积分图实现

```python
local_mean = _box_mean(arr, radius=3)          # 7×7 邻域均值
arr = np.clip(arr / (local_mean + 0.03), 0.0, 3.0)
```

retinex 思想：像素除以局部均值，消掉拍照时的光照不均与阴影渐变。
分母加 0.03 防除零并限制暗区增益；结果截到 3.0 抑制边缘除法尖峰。

局部均值用 **float64 积分图（前缀和差分）**计算，边界 replicate 填充：

```python
p = np.pad(arr, ((r, r), (0, 0)), mode="edge")
cv = np.cumsum(p, axis=0); cv = np.vstack([zeros, cv])
arr = (cv[w:, :] - cv[:-w, :]) / w          # 垂直方向；水平方向同理
```

好处有三：全链路浮点、不存在 uint8 量化噪声；复杂度 O(n²) 与滤波半径
无关；省去 Image ↔ ndarray 的往返转换。

### 2.4 全局标准化 + 二维 DCT 取低频

```python
arr = _normalize_zscore(arr)
coef = _DCT @ arr @ _DCT.T                  # 正交 DCT-II
feat = _l2_normalize(coef[:24, :24].reshape(-1))
```

DCT-II 用预计算的 64×64 正交矩阵实现（`C[k,i] = s(k)·cos(π(2i+1)k/2n)`），
二维变换就是两次矩阵乘法。取左上 24×24 = 576 个低频系数：低频刻画
页面整体构图，对压缩噪声、轻微形变、局部模糊天然钝感——这恰好是
"同一页不同拍摄"之间差异的主体。L2 归一化之后，欧氏距离与余弦距离
单调等价，取欧氏纯粹因为计算更省。

## 3. 颜色通道（768 维）：色度布局

绘本页面常靠颜色区分（不同角色、不同场景），单靠灰度布局不够。

```python
rgb = np.asarray(small, dtype=np.float64) + 1e-6
chroma = rgb / rgb.sum(axis=-1, keepdims=True)   # 逐像素色度归一化
planes = [_normalize_zscore(chroma[:, :, c]) for c in range(3)]
feat = _l2_normalize(np.stack(planes, -1).reshape(-1))
```

颜色表示选**色度归一化** `rgb/(r+g+b)` 而不是 HSV 色相，是一次明确的
取舍：色度对光照强度与白平衡增益不敏感，过曝区趋近中性灰、数值稳定；
HSV 的 H 通道在低饱和区（白底）接近随机——白纸上白色像素的色相毫无
规律，标准化后反而把噪声放大，实测会让错配显著增加。色度方案的实验
数据见[实验与阈值分析](实验与阈值分析.md) §2。

## 4. 拼接与距离

```python
return np.concatenate((struct, 0.6 * color))   # 576 + 768 = 1344 维
```

结构段权重 1.0、颜色段权重 0.6。颜色是辅助判据：权重扫描中 0.6 给出
最大的"同页对最大距离 / 异页对最小距离"间隔（§3 of 实验文档）。

## 5. 输入校验与边界行为

```python
if not isinstance(image_bytes, (bytes, bytearray, memoryview)):
    raise ValueError(f"... 收到 {type(image_bytes).__name__}")
if len(image_bytes) == 0:
    raise ValueError("... 空字节输入")
```

坏输入在入口即抛带类型信息的 `ValueError`，避免错误在库深处才暴露。
已验证的边界输入（均正常输出 1344 维有限向量）：PNG 大图、16px/64px
极小图、灰度、RGBA、CMYK JPEG、单色图、3000px 超大图。

## 6. 复杂度与耗时构成

| 环节 | 复杂度 | 实测占比 |
| --- | --- | --- |
| JPEG draft 解码 | O(像素/64) | 约 40%（大图更明显） |
| LCN 积分图 | O(64²)，与半径无关 | < 5% |
| DCT（两次 64×64 矩阵乘） | O(64³) | 约 20% |
| 其余缩放/归一化 | O(64²) + O(16²) | 约 40% |

单张典型 7~15 ms（含首张冷启动摊销），PNG 约 60~80 ms（无 draft 路径），
均远低于 100 ms 限值。DCT 矩阵等在模块加载时预计算，不计入单次调用。
